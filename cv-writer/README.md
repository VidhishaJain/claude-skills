# CV Writer

A Claude Skill that works like a hired CV counsellor. It tailors one CV to one job, programme or scholarship, explains every choice, and returns a file that passes applicant tracking systems (ATS) and reads well to a person in ten seconds.

The full instructions include my personal details, so this folder documents the design only.

## How it works

1. **Intake:** confirms the target, the job description or selection criteria, page limits, the latest master CV and the deadline
2. **Gather:** reads what is already known about my work before asking anything
3. **Decode the target:** lists the 10 to 20 skills and keywords the target rewards, in its exact wording, and checks the CV conventions for that country and sector
4. **Ask like a counsellor:** 3 to 5 focused questions at a time, digging for numbers, ownership and outcomes
5. **Write:** a stable master core plus tailored parts, with bullets that lead with the strongest true result
6. **Build:** a Word file and a PDF
7. **Check:** renders every page, extracts the plain text the way an ATS reads it, and reports keyword coverage and gaps

## Design choices

- **As strong as the truth allows.** It picks the most impressive true framing, scope and numbers, and never invents roles, results, titles, tools or dates. If a stronger claim needs a fact it doesn't have, it asks.
- **Ownership verbs match reality.** "Led" and "built" only where that's true. "Supported" or "contributed" otherwise, with the scope and result carrying the weight.
- **Client confidentiality.** Clients become descriptors such as "national healthcare diagnostics provider" unless a name is cleared to be public.
- **ATS-safe by default.** Single column, standard headings and fonts, no tables, icons or text boxes, and contact details in the body.
- **A change log for every version,** so the master CV stays clean.
